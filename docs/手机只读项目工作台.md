# 手机只读项目工作台

## 目标

手机打开固定网址，输入密码后查看项目办公室工作台。手机端只读，不提供任务提交、项目修改或文件写回。

## 访问地址

计划入口：

`https://lkaiopc.com/workbench/`

## 数据边界

- 发布内容只来自 `02_项目办公室/00_项目工作台/project-workbench-data.js` 的确认快照。
- 不发布 MAXNOTE 原始 Markdown、会议纪要、复盘记录或项目正文。
- 快照发布前使用 AES-256-GCM 加密。
- 密码只保存在 Mac mini 的 macOS 钥匙串中，不写入 Git、脚本或 Markdown。
- 手机解密后只在当前页面内存中显示，刷新页面需要重新输入密码。

## 首次设置

在 Mac mini 上进入网站工程目录：

```bash
cd "/Users/maxlee/Documents/MAXNOTE/02_项目办公室/04_课程网站/06_网站工程"
npm run workbench:password:set
npm run workbench:sync
npm run build
npm run check
```

设置密码时使用至少 12 位密码，不要把密码写入聊天记录或代码文件。

## 后续更新

项目工作台出现已确认的刷新后，必须同步手机端。使用下面这一条固定动作：

```bash
cd "/Users/maxlee/Documents/MAXNOTE/02_项目办公室/04_课程网站/06_网站工程"
npm run workbench:publish
```

该命令只处理手机只读工作台：重新生成加密快照、构建、检查、提交并推送 `/workbench/` 的必要产物；不会同步课程网站的其他内容。若存在未处理的 Git 暂存改动，命令会停止，避免把无关文件一并发布。

完成后用手机打开 `https://lkaiopc.com/workbench/`，输入既有密码查看最新快照。公开网址更新依赖 GitHub Pages 或部署平台完成构建。
